## 🎯 1. Project Overview & Objective
**REC - Aadhi EduEngine** is an AI-powered, real-time cinematic presentation engine designed to revolutionize digital education. It automatically transforms static textbook content, PDFs, and scripts into highly engaging, immersive video-like lessons that foster experiential learning.

It features an enthusiastic mascot (Aadhi), perfectly synchronized Text-to-Speech (TTS), kinetic typography, auto-generated Manim mathematical simulations, and AI-generated cinematic B-roll videos.

## ✨ 5. Core Engine Mechanics & Features

### A. The Master LLM Prompt & The JSON Contract
Located at the bottom of `index.html`, the system prompt forces the LLM to output a strict JSON structure.
- **Pedagogy:** Acts as a world-class educator (Carl Sagan/Sal Khan style), uses real-world analogies, and actively bridges concepts with rhetorical questions.
- **Zero-Redundancy:** Max 3-4 bullet points per slide. Learning Objectives are compressed into exactly one slide. 
- **The JSON Contract:**
  ```json
  {
    "concept_map": { "title": "...", "nodes": [...] },
    "scenes": [
      {
        "type": "content | ai_video | simulation | interactive",
        "title": "Slide Title",
        "side_panel": "image | chart | 3d_model | terminal | graph | manim | gif",
        "html": "<p>Point 1</p> <p>Point 2</p>",
        "narration": "Welcome! [SYNC] Here is point 1. [SYNC] And point 2.",
        "prompt": "Highly detailed prompt for image/video generation",
        "manim_code": "Python code if simulation"
      }
    ]
  }
  ```

### B. Kinetic Typography & Audio-Visual Sync (The `[SYNC]` Engine)
The frontend uses a custom engine (`window.slideSyncState`) that listens to the exact timing of the TTS audio to reveal HTML elements.
- **How it works:** The LLM inserts `[SYNC]` tags in the `narration` string. The frontend splits the string, calculates timing based on text length/speed, and cascades CSS classes (`cascade-hidden` -> `cascade-visible`) on DOM elements.
- **Critical Filtering Logic (Line 3779 in `index.html`):** The system uses `querySelectorAll` to find animateable elements (`h2, h3, p, li, .math-block, pre`). 
  - *Crucial Detail:* It implements a **DOM descendant filter** so that if an element is nested inside another animateable element, it is ignored by the tracker. This prevents array index misalignments with the `[SYNC]` markers.
  - *Crucial Detail:* Media tags (`img`, `table`, `.board-image-placeholder`, `.context-gif`) are **intentionally excluded** from the sync tracker. They render visibly immediately upon slide load so they don't consume a `[SYNC]` tag meant for text.

### C. The Dynamic Sidebar (`side_panel`)
Slides support a dynamic side panel that can instantly render:
1. `image`: AI-generated contextual images (via Unsplash/DALL-E).
2. `chart`: Chart.js animated data visualizations.
3. `3d_model`: Interactive 3D models (atom, torus, box) via Three.js/ModelViewer.
4. `quiz`: Interactive multiple-choice knowledge checks.
5. `terminal`: Live hacker terminal output typing.
6. `graph`: Interactive JSXGraph Cartesian coordinate plots.
7. `manim`: Small-scale Manim animations.
8. `gif`: Auto-fetched contextual Giphy reactions.
9. `skill_tree`: A visual concept map tracking the student's progress.

### D. AI Cinematic Videos (`ai_video`)
Full-screen, immersive cinematic scenes. The frontend handles these dynamically:
- B-roll videos (no native audio) are automatically rendered with `loop muted autoplay` attributes.
- **Sync Logic:** The presentation engine seamlessly loops the video in the background while waiting **strictly for the TTS narration to finish** before auto-advancing (`hasAudio` lock). 
- If the user explicitly selects "Native Video Audio" (`ai_audio_source === 'video'`), it smartly bypasses the TTS lock and relies on the video's internal `onended` event.

## 🛠️ 6. Latest Critical Fixes Applied (Context for New AI)
If the new AI needs to know what was *just* fixed, here is the log:

1. **Database Migration Crash (`user_id` OperationalError):** 
   - *Fix:* The backend schema was updated to include full JWT user authentication (`user_id` in `Project`), but SQLite was crashing on schema mismatch. The old database tables were safely dropped, allowing SQLAlchemy's `create_all` to automatically rebuild the schema on server restart.
2. **AI Video Auto-Advance Deadlock:**
   - *Bug:* Cinematic B-roll videos (5 secs) were shorter than the TTS narration (15 secs). The sync engine was waiting for the video to `onended`, but also waiting for the audio, causing it to freeze on the last video frame.
   - *Fix:* Added `loop` to B-roll videos. Updated `isReadyToAdvance()` logic to completely ignore the video length for B-roll and rely **100% on the TTS audio length** for auto-advancement. 
3. **Typography & UI Scaling:**
   - *Fix:* Main slide titles and section headings were overflowing on smaller boards. CSS bounds were aggressively tightened (e.g., `clamp(1.4rem, 2.2vw, 2.2rem)`) to ensure elegant scaling when the dynamic side panel pushes the board inward.
4. **Table & Image Sync Destruction:**
   - *Bug:* The system was forcing `table`, `table rows`, and `img` to wait for a `[SYNC]` marker, but the LLM only generates markers for text. This caused permanent invisibility for tables and catastrophic sync misalignment for the rest of the slide text.
   - *Fix:* Explicitly removed `img`, `table`, and `.board-image-placeholder` from the `animateItems` tracking array. They now render beautifully and immediately upon slide load, allowing the text elements to perfectly align 1-to-1 with the LLM's `[SYNC]` markers.
